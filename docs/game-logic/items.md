# 道具系统

Echo Trace 的道具系统是游戏战术深度的核心。所有道具分为 **4 个稀有度等级** (T1-T4)，按功能划分为 **攻击、生存、侦察、综合** 四大类。

## 道具稀有度

| 等级 | 名称 | 颜色标识 | 刷新概率 | 特点 |
|------|------|---------|---------|------|
| **Tier 1** | Common | 白色 | 60% | 基础效果，高刷新率 |
| **Tier 2** | Rare | 蓝色 | 25% | 战术增强，中等稀有度 |
| **Tier 3** | Epic | 紫色 | 12% | 强力效果，低刷新率 |
| **Tier 4** | Legendary | 金色 | 3% | 改变战局，极度稀有 |

---

## 攻击类 (Offense)

**限制**：同一时间仅能存在一种主炮强化状态。

### Tier 1: 超级穿甲弹

**核心数值**：20% 真实伤害  
**消耗**：3 发  
**效果**：强化下 3 次射击。无视护甲直接扣除总血量的 20%。

**使用场景**：
- 对抗高护甲目标（AI Boss、DEFENSE 倾向玩家）
- 快速击杀血量较低的敌人
- 穿透"绝对防御"之外的所有防御手段

**反制**：
- 使用 **"绝对防御"** (T2) 完全免疫
- 使用 **"主动防御"** (T3) 短时免疫

**战术建议**：
- Phase 2 冲突阶段储备至少 2 个
- 配合 **"全境扫描终端"** (T3) 锁定目标后使用
- 对 AI Boss 造成稳定伤害（无视其高护甲）

---

### Tier 2: 光学折射效应

**核心数值**：25 伤害 / 3 次反弹  
**消耗**：3 发  
**效果**：弹道碰撞墙壁可反弹 3 次，具有 50% 护甲穿透。

**使用场景**：
- 狭窄通道战斗
- 利用墙体反弹攻击躲在掩体后的敌人
- 多角度攻击同一目标

**技巧**：
- 计算反弹角度，实现间接打击
- 在 L 型通道中使用可命中转角后的敌人
- 配合地形优势封锁逃跑路线

**物理特性**：
- 反弹角度遵循"入射角 = 反射角"原则
- 每次反弹伤害不衰减
- 反弹 3 次后子弹消失

---

### Tier 3: 超视距·电磁炮

**核心数值**：75 伤害 / 10% 穿透  
**消耗**：1 发  
**效果**：**[瞬时射线]** 无视障碍。预警 0.5 秒，伤害随穿墙衰减。

**使用场景**：
- 跨墙狙击
- 突破防御阵地
- 击杀躲在建筑物后的敌人

**机制详解**：
- 发射前 0.5 秒出现红色激光预警线
- 伤害计算：`75 × (1 - 墙体数量 × 10%)`
- 最多穿透 5 堵墙（最低伤害 37.5）

**反制**：
- 预警阶段快速移动躲避射线
- 躲在多层墙体后降低伤害
- 使用 **"绝对防御"** 完全免疫

---

### Tier 4: 超视距·精通天理

**核心数值**：125 初始 + 100 持续伤害  
**消耗**：1 发  
**效果**：**[轨道打击]** 长按 Space 蓄力，蓄力越久射程越远。松开后对末端**超大半径**区域造成 125 点伤害，并产生持续 2 秒的余烬（25 点/0.5 秒）。

**全图反制机制**：
- 蓄力阶段：全图广播弹幕提醒
- 落下前 1 秒：地面出现巨型预警圈（半径 5m）
- 音效提示：低沉的充能声 + 尖锐的警报音

**伤害计算**：
- 直接命中：125 点（普通坦克 100 HP，秒杀）
- 余烬持续：4 次 × 25 点 = 100 点
- 总伤害：最高 225 点

**战术意义**：
- 一击秒杀无护甲目标
- 封锁撤离点（余烬区域持续伤害）
- 清空区域内所有敌人
- 对 AI Boss 造成重创

**反制策略**：
- 看到预警圈后立即撤离（1 秒反应时间）
- 使用 **"闪灵瞬步"** (T1) 快速逃离
- 使用 **"绝对防御"** (T2) 原地免疫

## 生存类 (Survival)

**限制**：防御类道具激活期间，主炮装填速度降低 30%。

### Tier 1: 回光返照

**核心数值**：+30% HP / +20 Armor  
**消耗**：1 次  
**效果**：立即修复。超出上限部分转化为临时护甲（10 秒后衰减）。

**使用场景**：
- 低血量紧急恢复
- 战斗前提前叠护甲
- 配合 DEFENSE 战术增加生存能力

**技巧**：
- 满血使用可获得临时护甲加成
- Phase 2 冲突阶段必备道具
- 与 **"绝对防御"** 配合使用延长生存时间

**数值示例**：
- 普通坦克（100 HP）：恢复至 130 HP，超出 30 转化为护甲
- DEFENSE 倾向玩家（120 HP）：恢复至 156 HP，超出 36 转化为护甲

---

### Tier 2: 绝对防御

**核心数值**：3.0 秒无敌  
**消耗**：1 次  
**效果**：相位偏移。期间免疫所有伤害，但无法移动和攻击。

**使用场景**：
- 躲避 **"精通天理"** (T4) 轨道打击
- 在撤离点撤离时免疫攻击（F 键交互不中断）
- 被多人围攻时拖延时间等待队友支援

**限制**：
- 无法移动（可以转向）
- 无法攻击
- 无法使用其他道具

**视觉效果**：
- 玩家坦克外层出现蓝色能量护盾
- 子弹命中护盾时产生粒子特效

**战术建议**：
- Phase 3 逃离阶段保留至少 1 个
- 在撤离点使用可确保安全撤离（3 秒撤离 = 刚好覆盖）
- 配合队友吸引火力

---

### Tier 3: 主动防御

**核心数值**：2.0 秒全免疫 + 解锁  
**消耗**：1 次  
**效果**：清除所有标记/追踪状态，免疫侦察锁定。

**清除效果**：
- **"超视距·追踪"** (T2) 的雷达标记
- **"全境扫描终端"** (T3) 的坐标锁定
- 所有侦察类道具的追踪效果

**使用场景**：
- 被 **"全境扫描终端"** 锁定后立即清除
- 逃离追击时清除追踪状态
- 短时间内免疫伤害并解除控制

**与"绝对防御"的区别**：
| 特性 | 绝对防御 (T2) | 主动防御 (T3) |
|------|--------------|--------------|
| 持续时间 | 3.0 秒 | 2.0 秒 |
| 移动能力 | ❌ 不能移动 | ✅ 可以移动 |
| 攻击能力 | ❌ 不能攻击 | ✅ 可以攻击 |
| 清除追踪 | ❌ 不清除 | ✅ 清除所有标记 |

---

### Tier 4: 我就是柠白号

**核心数值**：Boss 级属性同步  
**消耗**：1 次  
**效果**：**[数值重塑]** 瞬间将当前玩家的 HP 上限、基础 HP、护甲值完全同步为 **Boss-柠白号** 的数值模板。此状态下体积可能增大，成为全场焦点。

**属性同步**：
| 属性 | 普通玩家 | 柠白号 |
|------|---------|--------|
| HP 上限 | 100 | 300 |
| 基础 HP | 100 | 300 |
| 护甲值 | 50 | 150 |
| 移动速度 | 5.0 | 4.0 |
| 伤害 | 25 | 40 |

**战术意义**：
- 从"猎人"变成"小 Boss"
- 需要多名玩家配合才能击杀
- 适合逆风翻盘或保护队友撤离
- 吸引火力为队友创造机会

**缺点**：
- 体积增大后更容易被集火
- 移动速度降低
- 成为全场焦点（容易被围攻）

**反制策略**：
- 多人配合使用 **"超级穿甲弹"** (T1) 真实伤害
- 使用 **"超视距·电磁炮"** (T3) 穿墙攻击
- 利用地形优势风筝（保持距离持续输出）

## 侦察类 (Recon)

**限制**：单次效果不叠加，持续触发时刷新时间。

### Tier 1: 视距提升

**核心数值**：+20% 视野半径  
**持续时间**：15.0 秒  
**效果**：扩大迷雾消除范围。

**使用场景**：
- Phase 1 搜索阶段探索地图
- Phase 2 冲突阶段提前发现敌人
- 配合 RECON 战术最大化视野优势

**数值示例**：
- 普通视野半径：8m
- 提升后视野半径：9.6m
- RECON 倾向 + 视距提升：12m（+50%）

---

### Tier 2: 光锥之外

**核心数值**：270° 补角视野  
**持续时间**：10.0 秒  
**效果**：牺牲正前方 90° 视野，获得侧后方视野，防绕后神技。

**视野变化**：
```
正常视野：前方 180° 锥形
光锥之外：后方 270° 扇形（牺牲正前方 90°）
```

**使用场景**：
- 在通道中行走，防止被从后方偷袭
- 逃跑时观察追击者位置
- 守点战术（背对撤离点，观察周围）

**技巧**：
- 配合队友正面作战，自己负责侦察后方
- 在 Phase 3 逃离阶段观察追击者
- 与 **"无形之物"** (T3) 配合实现完美隐蔽

---

### Tier 3: 全境扫描终端

**核心数值**：5m 半径暴露  
**持续时间**：30.0 秒  
**效果**：锁定最近玩家并全图同步坐标。强制隐身单位显影。

**机制详解**：
- 每 2 秒更新一次最近玩家位置
- 在所有玩家的小地图上显示红色标记
- 穿透 **"无形之物"** (T3) 隐身效果
- 显示目标的移动轨迹（5 秒延迟）

**使用场景**：
- 追击使用 **"无形之物"** 隐身的玩家
- Phase 2 配合雷达脉冲锁定高价值目标
- 团队协作围剿单个敌人

**反制**：
- 使用 **"主动防御"** (T3) 清除标记
- 使用 **"全频段阻塞干扰"** (T4) 屏蔽雷达
- 快速移动避免被围攻

---

### Tier 4: 全频段阻塞干扰

**核心数值**：全图黑盒化  
**持续时间**：30.0 秒  
**效果**：**[系统瘫痪]** 屏蔽全地图所有玩家的雷达、小地图显示，并使所有已激活的道具处于暂时不可用/静默状态。

**影响范围**：
- ❌ 小地图完全黑屏
- ❌ 雷达脉冲不显示
- ❌ **"超视距·追踪"** (T2) 失效
- ❌ **"全境扫描终端"** (T3) 失效
- ✅ 视野系统正常（FOV 不受影响）

**战术意义**：
- 进入"盲战"阶段
- 削弱依赖侦察道具的玩家
- 适合潜行流或准备逃离包围圈
- RECON 倾向玩家受影响最小（视野优势仍存在）

**适用场景**：
- Phase 2 冲突阶段打破雷达锁定
- Phase 3 逃离阶段掩护撤离
- 团队协作中断敌方信息优势

## 综合类 (Utility)

### Tier 1: 闪灵瞬步

**核心数值**：2.0m 瞬移  
**刷新权重**：High  
**效果**：向履带朝向瞬间移动。不可穿墙。

**使用场景**：
- 躲避子弹
- 快速穿越开阔地
- Phase 3 撤离阶段冲刺
- 躲避 **"精通天理"** (T4) 预警圈

**技巧**：
- 连续使用可实现快速位移（冷却时间 1 秒）
- 配合转向实现 Z 字形机动
- 在撤离点附近储备 2-3 个以备不时之需

**限制**：
- 不可穿墙（碰到墙体停止）
- 瞬移距离固定 2.0m
- 冷却时间 1 秒

---

### Tier 2: 超视距·追踪

**核心数值**：脉冲雷达显示  
**刷新权重**：Med  
**效果**：小地图每 2.0 秒闪烁显示最近玩家红点。仅使用者可见。

**使用场景**：
- 追击逃跑的玩家
- 在迷雾中锁定敌人位置
- 配合 **"超视距·电磁炮"** (T3) 跨墙狙击

**反制**：
- 使用 **"主动防御"** (T3) 清除追踪
- 使用 **"全频段阻塞干扰"** (T4) 屏蔽雷达
- 快速移动避免被锁定

---

### Tier 2: 残缺的万能许愿机

**核心数值**：简化 MCP 执行  
**刷新权重**：Low  
**效果**：**[有限逻辑干预]** 接收玩家简单指令，在受限权限下实现基础愿望。

**权限等级：残缺版**

| 功能 | 是否支持 |
|------|---------|
| 查询信息（地图、玩家位置） | ✅ |
| 小范围传送（< 5m） | ✅ |
| 临时属性提升（+10% HP/速度） | ✅ |
| 大范围传送（> 5m） | ❌ |
| 修改游戏参数 | ❌ |
| 召唤实体 | ❌ |

**使用示例**：
- "传送到最近的补给箱"
- "显示 AI Boss 位置"
- "提升移动速度 10%，持续 5 秒"

详见 [MCP Server API](/api/mcp-server.html)。

---

### Tier 3: 无形之物

**核心数值**：完全透明化  
**刷新权重**：Low  
**效果**：坦克模型与足迹消失。攻击或撞击后失效。

**隐身机制**：
- 视觉隐身：敌人无法看到坦克模型
- 足迹隐藏：地面不留下履带痕迹
- 小地图隐藏：不显示在小地图上

**失效条件**：
- 攻击（开火）
- 撞击墙壁或其他玩家
- 被 **"全境扫描终端"** (T3) 强制显影

**使用场景**：
- 潜行接近敌人
- 躲避 AI Boss 追击
- 埋伏撤离点

---

### Tier 4: 万能许愿机

**核心数值**：由 MCP 定义执行  
**刷新权重**：Very Low  
**效果**：**[完整逻辑干预]** 接收玩家指令。在 MCP 允许的底层权限内实现愿望。

**权限等级：完整版**

| 功能 | 是否支持 |
|------|---------|
| 所有残缺版功能 | ✅ |
| 大范围传送（直达撤离点） | ✅ |
| 清空周围障碍 | ✅ |
| 强制交换位置 | ✅ |
| 修改游戏参数 | ❌ |
| 操控 Boss 行为 | ❌ |

**使用示例**：
- "传送到撤离点"
- "清除前方 10m 内的所有墙体"
- "与最近的玩家交换位置"

---

### Tier 4: 开发者遗忘的命令行

**核心数值**：扩展 MCP 权限  
**刷新权重**：Ultra Rare  
**效果**：**[系统级干预]** 继承万能许愿机的所有能力，并额外获得扩展 MCP 权限。

**权限等级：开发者版**

| 功能 | 是否支持 |
|------|---------|
| 所有完整版功能 | ✅ |
| 修改游戏参数（缩圈速度、伤害倍率） | ✅ |
| 召唤实体（补给箱、引擎） | ✅ |
| 操控 Boss 行为（命令攻击目标） | ✅ |
| 跳过阶段 | ✅ |

**使用示例**：
- "降低缩圈速度 50%"
- "在我的位置生成 5 个 T4 补给箱"
- "命令 AI Boss 攻击玩家 [名称]"
- "跳过当前阶段"

**终极战术工具**，但极度稀有（刷新概率 < 0.1%）。

## 道具获取

### 地面掉落

- **Phase 1**：最多 20 个道具
- **Phase 2**：最多 15 个道具
- **Phase 3**：最多 10 个道具
- **刷新间隔**：5 秒

### 商人购买

- **商店刷新**：100 Credits（Phase 1 免费一次）
- **道具价格**：
  - T1: 50-100 Credits
  - T2: 150-250 Credits
  - T3: 300-500 Credits
  - T4: 1000+ Credits

### 击杀掉落

- 击杀玩家：掉落其背包中的所有道具
- 击杀 AI Boss：掉落 2-3 个 T3-T4 道具

## 道具策略

### Phase 0 选择

- **RECON**：优先收集侦察类道具（视距提升、追踪）
- **DEFENSE**：优先收集生存类道具（回光返照、绝对防御）
- **TRAP**：优先收集攻击类道具（穿甲弹、电磁炮）

### Phase 1 储备

- 至少 1-2 个 T2+ 道具
- 保留 **"闪灵瞬步"** (T1) 用于逃生
- 积累 Credits 购买 T3 道具

### Phase 2 对抗

- 使用 **"超级穿甲弹"** (T1) 快速击杀
- 保留 **"绝对防御"** (T2) 保命
- 使用 **"全境扫描终端"** (T3) 锁定目标

### Phase 3 逃离

- 使用 **"闪灵瞬步"** (T1) 快速位移
- 使用 **"绝对防御"** (T2) 在撤离点免疫攻击
- 如果持有 T4 道具，优先使用（改变战局）
